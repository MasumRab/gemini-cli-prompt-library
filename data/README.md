# Jules Operational Data

This directory contains operational state files generated by the Jules AI agent CLI.

## Files

| File                          | Description                                                         |
|-------------------------------|---------------------------------------------------------------------|
| `jules_sessions.json`         | Session registry — list of all sessions with metadata and outputs   |
| `jules_bolt_activities_full.json` | Activity log for the Bolt agent                                 |
| `jules_sentinel_activities_full.json` | Activity log for the Sentinel agent                           |
| `jules_sources.json`          | Source configuration for Jules (repos, doc sources, etc.)          |

## Usage

These files are managed by the Jules CLI tools in `tools/sessions/` and `tools/pr/`.
They are gitignored to prevent accidental commits — generate summaries using
`scripts/generate_session_summaries.py` if you need committed records.

## Summary Standard

See `docs/guides/session_summary_standard.md` for the standard summary format.
