# Jules PR Verification Runbook

This runbook defines the automated and manual verification steps for any Pull Request generated by a Jules session.

## Automated Safety Audit
Every completed session should undergo an automated safety audit before manual review.

**Run the auditor:**
```bash
python3 -m tools.pr.jules_audit_session_pr --session <SESSION_ID>
```

### Safety Triggers (Blocking)
If any of these fail, **DO NOT MERGE**. Close the PR immediately.

1. **Build Artefacts:** No `.pyc`, `__pycache__`, `dist/`, or `build/` files allowed.
2. **Shell Variables:** No unexpanded `$PWD` or `$PROJECT_ROOT` in configuration files.
3. **Read-only Files:** No changes to `analysis/*.ipynb` files.

### Quality Warnings
These indicate the PR may need further work but are not strictly blocking:
1. **Missing Tests:** Code changes without corresponding test updates.
2. **Stub Implementations:** Presence of "TODO" or "pass # stub".

## Manual Review Checklist
- [ ] Code follows project style conventions.
- [ ] Logic addresses the core issue in the ticket.
- [ ] No regression in existing functionalities.
- [ ] Documentation updated if necessary.

## Multi-Repo Verification
If the changes affect multiple repositories, use the multi-repo tool to check consistency:
```bash
./tools/check_all_repos.sh
```
