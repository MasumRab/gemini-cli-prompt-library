## Development Environment

### Prerequisites
- Python 3.9+
- `git` CLI for repository operations
- GitHub CLI (`gh`) for API access

### Setup
```bash
# Install dependencies (if any)
pip install -r requirements.txt  # if present

# Run tests
python -m pytest tests/ -v
```

### Configuration
Environment variables can override defaults:
- `GRAPHITE_TRUNK_BRANCHES` — Comma-separated roots (default: "main")
- `GRAPHITE_PRIMARY_REMOTE` — Git remote name (default: "origin")
- `GRAPHITE_AGENT_OUTPUT_DIR` — Output directory (default: ".graphite-agent/outputs")
- `GRAPHITE_AGENT_SCHEMA_VERSION` — Schema version (default: "6.4")
- `GRAPHITE_DRY_RUN` — Enable dry run mode (default: "0")
